Security Disclosure

IndieMark is a local-first prototype and has not received an independent security audit. Browser storage is not encrypted by this application. Anyone with access to the same browser profile may be able to access local records.

Safe use

Keep backups in a secure location, avoid entering sensitive personal data, use an up-to-date browser and do not treat watermark recovery as cryptographic verification.

For a security concern, contact the project maintainer through the repository issue tracker. Do not include private data in a public issue.
