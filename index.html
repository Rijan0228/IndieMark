HOW TO READ THESE RESULTS
RecoveredThe payload was recovered and its ID matched the baseline ID.
Different / incompleteA payload was detected, but it did not match the baseline ID.
Not recoveredThe extraction engine could not recover a valid payload.

These are local prototype tests, not independent forensic validation. Canvas re-rendering is not a real screenshot, and results do not predict how every platform will process an image.
